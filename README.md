# CS-370
#What I Did in This Project
#For this project, I worked on building a pirate intelligent agent using reinforcement learning. The course provided the game environment, the maze layout, and the .py files that controlled how the game worked. I was not allowed to change those files. My job was to complete the Q‑learning and neural network code inside the Jupyter Notebook. I wrote the training loop, the exploration strategy, the replay memory, and the updates that helped the agent learn to reach the treasure.

#How This Connects to Computer Science
#Computer scientists solve problems by creating systems that are reliable, efficient, and able to handle real‑world challenges. Reinforcement learning is one example of this—it teaches an agent to learn from experience and make better decisions over time. This same idea is used in robotics, healthcare, and many other fields.

#How I Approach Problems as a Computer Scientist
#I break problems into smaller steps, look at the constraints, and test ideas one piece at a time. I use debugging, experimentation, and clear documentation to understand what is happening and improve the solution. This project helped me practice analyzing results, adjusting parameters, and thinking logically about how an agent learns.

#My Ethical Responsibilities
